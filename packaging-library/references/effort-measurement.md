# 如何验收节省 70% 工作量

“至少 70%”是目标，本套件尚未通过真实新手计时实验验证。统计人工有效操作时间，包括看教程、修错、反复确认、人工修订；AI 后台运行等待另列为交付耗时，不能把两者混在一起。

公式：人工节省率 = 1 - 使用套件的人工分钟数 / 同范围从零制作的人工分钟数。

对比必须做到：相同产品数、相同复杂度、相同交互与画面验收标准，不能用没有标签的粗模与完整精细模型相比。首次软件安装与培训单列，并同时给出“含首次准备”和“后续批次”结果。没有可比的从零基线时，先报告实际耗时，不能声称已达标。

建议一轮验证包括圆罐、泵瓶、滴管瓶，并至少加入一款模板不直接适用的产品；不能只选三个最简单的样例。由一位未参与原项目的人操作，记录卡住的位置。

| 工作 | 框架已省掉什么 | 仍会变化 |
|---|---|---|
| 页面搭建 | 浏览、搜索、收藏、原图、响应式布局 | 名称、配色、品牌与信息结构确认 |
| 3D交互 | 加载、旋转、展开、复位、错误回退 | 部件节点及展开距离 |
| 素材准备 | 原图保留、预览尺寸、数据连接 | OCR确认、抠图与标签可读性 |
| 建模 | 基础形体、材质字段、导出和接入 | 特殊瓶型、曲面标签、玻璃表现 |
| 验收 | 文件/节点检查与明确检查清单 | 对照原图、真实设备检查 |
| 发布 | 可重复的候选/回退流程 | 域名、托管、权限与实际上线 |

以固定底座节省重复劳动最可靠。复杂异形瓶可能仍花较多建模时间，不能保证每一款都省 70%。把实测中重复卡住的步骤再收进脚本，而不是增加更多术语和手填表。
