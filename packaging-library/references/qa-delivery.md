# 验收和交付

## 必须完成的验证

```sh
python <SKILL>/scripts/check_project.py <项目>
cd <项目>
npm test
npm run build
npm run preview
```

用真实浏览器访问本地 HTTP 地址，不能只双击 Vite 源 HTML。检查：

- 首页和总览：数量、产品对应关系、所有图像加载；搜索、无结果、清空筛选；收藏与刷新；中英文和键盘关闭。
- 原海报：查看、返回、下载保持同一产品；原图字节未被优化图覆盖。
- 每款 3D：首帧可见；合拢、50%、100%、回零；横向旋转、底部和视角复位；按钮和滑块都能操作。
- 关闭 3D 后取消请求、释放画布；再次打开正常。加载失败有重试和原图回退。首页未打开 3D 前不请求全部模型。
- 1440px 桌面及至少 390px/320px 窄屏，无水平溢出、挡住按钮和模型裁切。窄屏模拟不等于真实手机/触控板验证。
- 减少动态效果、键盘焦点、文字对比、非颜色状态提示保留。

性能记录包含网络条件、缓存状态、模型字节数、点击至首帧时间。`renderer.render()` 返回并不是 GPU 完成时间；不能承诺所有设备 60FPS。

## 交付结构

项目源码 + 可运行构建 + 每款模型源文件 + 原海报 + 验证报告。报告逐款包含：ID、原图摘要、模型摘要、部件列表、闭合/全展截图、测试环境、未知信息和当前状态。单独记录“海报数量/独立结构数量/通过验收的模型数量”。

用户可读说明只需写如何打开、在哪里放下一批海报、怎样选择风格、怎样要求 AI 修订。生成器错误由 AI 处理，不把长技术日志当作说明书。

## 发布

独立静态包可本地预览，不提供账户权限或服务端数据库。上传公开服务器会使资源公开可访问；如要求客户私有库，应沿用现有权限系统或在部署环境建立服务端鉴权。禁止把旧认证 API 地址复制进别人的项目充当登录。

仅有构建通过不能写已上线。正式发布需要当前基线、资源清单、发布回执和线上检查。用户已给发布授权则按其范围继续；未给发布授权则交付可审查候选版本。现有库流程见 existing-library.md。
