PACKAGING LIBRARY · REUSABLE KIT · V1

交海报，选风格。
让 AI 搭好你的包材库。

现成网页底座 + 展示级 3D 流程 + 可复用 Skill。把反复搭页面、调交互、连素材的工作留在框架里。

目标：下一位使用者不需要会写代码或建模。AI 完成技术工作，她负责提供海报、选择风格，并确认产品有没有做对。

你需要准备什么

  1. 产品海报：直接提供图片文件夹，PNG / JPG / WebP 均可。产品和文字越清楚，返工越少。
  2. 一种风格：从下面三种中选一个；暂时没有想法就选自然温润。

自然温润

奶油底色、暖中性色，适合植物、身体护理和日常护肤。

natural

清透简洁

浅冷色、干净留白，适合精华、透明包装与洁净感产品。

clear

鲜明活泼

粉色与明亮强调色，适合个性护理与年轻化产品。

bold

三种预设共用网页布局，调整配色与展示气质。风格不会改掉你的瓶型、包装颜色或品牌文字；需要不同版式时再明确提出。

之后会发生什么

海报导入 → AI 对照原图 → 选择并校准模型 → 生成交互展示 → 检查与修正 → 交付

你最后只需核对：是不是这款产品、比例是否像、盖泵有没有做错、文字是否正确、展开是否合理。发现问题直接说，例如“盖子太高，按海报再矮一点”，AI 修改对应产品。

先看现成示例

让 AI 按仓库首页 README 的命令安装依赖并运行 npm run dev，浏览器即可打开三款现成示例。GitHub 源码版本不包含预构建的 dist。示例包括磨砂膏罐、日常乳液泵瓶和身体护理油单瓶。

要制作自己的库，使用上面的任务文字。AI 会新建单独项目；例子中的品牌与产品不会自动变成你的新产品。

“节省 70%”怎么判断

70% 是验收目标，尚未做真实新手计时验证。应比较相同产品数量、复杂度和验收标准下的人工操作时间，并把首次安装单列。页面和交互可直接复用；特殊瓶型、玻璃表现、曲面标签仍可能需要逐款修订。

一张海报可以做展示级外观模型。真实尺寸、背面和隐藏机构无法仅靠一张图确认；工厂开模、制造 CAD 和打样需要额外实测资料。
